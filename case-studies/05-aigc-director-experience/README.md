# AIGC 短剧导演：把“我一直这么拆”变成镜头判断规则

> “我会把短剧脚本拆成 AIGC 能做的镜头，但很多判断都是凭经验，很难讲清楚。”

这是基于真实 Runtime 对话整理的教学案例。人物与情节经过改写和复合设计，不对应未经处理的真实项目；案例只演示如何提取导演方法，不验证某套制作方法普遍更优。

## 1. 用户一开始只有什么

用户能处理 1–2 分钟短剧，但没有现成方法文档。教学场景是一段悬疑戏：女生回到出租屋，发现桌上有仍然温热的咖啡；纸条写着她晚回来了 17 分钟；手机收到一张她此刻背影的照片；最后发现衣柜门留着一条缝。

用户知道有些动作不值得逐步生成、有些细节绝不能提前揭示，却还没有把这种“凭感觉”的拆镜过程写成判断规则。

## 2. Skill 没有立刻做什么

- 没有逐句把剧本翻译成镜头清单。
- 没有先问使用哪个模型或要求填写镜头参数。
- 没有把“更容易生成”自动放在戏剧效果之前。
- 没有延伸到 Midjourney、Kling、Seedance 的具体 Prompt 编写。

## 3. 它问了什么

1. **这段戏里，哪些时刻真正改变了观众知道的信息或人物的情绪？** 这能找出镜头切分依据，而不是跟着句号切镜头。
2. **哪些动作只是操作过程，哪些动作本身就是人物决定？** 同样是开门或拿手机，有的可以省略，有的承载犹豫、确认或恐惧，不能只按生成难度处理。
3. **如果连续动作不稳定，你会怎样替换？替换后保住了什么戏？** 这个问题把制作经验变成可审查的替代规则。
4. **什么信息绝不能提前出现？** 它把悬念管理变成 Hard Constraint，而不是靠最后凭感觉修剪。

## 4. 从案例中发现了什么

- 镜头边界来自信息、情绪、关系和节奏变化，不来自剧本文字的逐句对应。
- “戏剧动作”与“操作过程”需要分开；没有戏的连续操作可以跳过。
- 动作难生成时，可以用动作前状态与动作后状态表达结果，减少脆弱连续性。
- 如果动作承载人物决定或情绪，就不能为了易生成而删除。
- AIGC 风险是改写触发器，不是最高原则；替代表达还要保住甚至强化戏剧效果。
- 本应延迟揭示的信息不能因画面方便而提前出现。

## 5. 从经验到规则

| 原始经验 | 提取出的判断 | 可以写进 Skill 的规则 |
| --- | --- | --- |
| “我不会每句话都拍” | 只在戏发生变化时切镜头 | 先标记信息、情绪、关系或节奏变化，再设计镜头 |
| 连续操作容易崩 | 过程不一定是戏 | 无戏的操作可改为动作前状态 → 动作后状态 |
| 有些困难动作不能删 | 动作可能承载人物决定 | 删除前说明该动作承载的戏；无法保留则不得省略 |
| 悬念要控制揭示顺序 | 画面信息也参与叙事 | 建立 reveal constraint，不提前展示未到时机的信息 |
| 降难度后还要好看 | 技术替代必须服务戏剧 | 每次简化都说明保留了什么戏，以及省略为何成立 |

## 6. 最终找到的 Skill

**Skill Statement**：当 AIGC 短剧导演需要把 1–2 分钟剧本拆成可制作镜头时，通过戏剧变化识别、动作价值判断和风险替代，在降低生成难度的同时保留叙事与情绪。

- **适用边界**：导演判断与 AIGC 制作拆解；不编写具体模型 Prompt，不代替成片剪辑或制片排期。
- **核心 Workflow**：提取戏剧变化 → 区分戏剧动作与操作过程 → 标记生成风险 → 设计保戏的替代表达 → 检查揭示顺序和节奏。
- **Hard Constraints**：不能逐句机械翻译；不能只为易生成删除人物决定；不能提前泄露悬念；每次降难度都要说明保住了什么戏。
- **Output**：戏剧节拍、镜头功能、必要动作、可替代过程、风险说明与揭示顺序。
- **Check / Repair**：检查每个镜头是否推动信息或情绪、替代是否削弱戏、悬念是否提前；失败时修复表达方式，不默认删除关键动作。

## 7. 为什么这不是普通 Prompt

普通 Prompt 可以把一段剧本一次性改写成分镜。这里提取的是为什么切镜、什么时候能跳过动作、什么动作不能省、技术风险如何触发改写，以及改写后怎样检查戏仍然成立。它能处理新的剧本，而不只复述这段出租屋情节。

## 8. 你可以照着怎么开始

```text
$build-your-own-skill

我经常把短剧脚本拆成 AIGC 可以制作的镜头。
很多判断我会做，但从来没有整理过。
请用一段我最近拆过的戏，追问我为什么保留、跳过或改写镜头，
先帮我提取方法，不要创建文件。
```

## 9. 这个案例真正值得学什么

- 专家的“顺手”动作里，常藏着条件、例外和优先级。
- 技术限制应触发专业判断，而不是取代专业目标。
- 好规则不仅告诉 AI 怎么简化，还要求它解释简化保住了什么价值。
