# Real Case Studies

这些案例不是为了展示一份“漂亮的 `SKILL.md`”，而是展示一个真实 Skill 如何被发现、拆解、构建和诊断。

`examples/` 展示“一个 Skill 最后长什么样”；`case-studies/` 展示“一个真实用户如何从不同起点一步步走到 Skill”。

| 你现在手里有什么 | 案例 | 路径 |
| --- | --- | --- |
| 只有工作经验，不知道怎么整理 | 从专业经验到 Skill | [Experience → Skill](01-experience-to-skill/) |
| 已经有一条越来越长的 Prompt | 从长 Prompt 到 Skill | [Prompt → Skill](02-prompt-to-skill/) |
| 已经有 Skill，但不好用 | Review / Repair | [Review → Repair](03-review-and-repair/) |

### Case 01

没有现成 Prompt，从视觉设计师处理模糊活动 Brief 的真实工作经验开始，逐步提取判断、约束、流程与测试。

### Case 02

已有一条长期使用、效果不错但难以维护的成熟 Prompt，将其中隐含的结构拆成明确 Workflow、永久视觉 DNA、检查与修复机制。

### Case 03

已有能运行的 Skill，不重新构建；先定位不稳定行为的根因，再提出最小修复（Minimum Change）与回归测试。

不要只看最终文件。真正值得学习的是：为什么问这些问题、为什么做这些判断、为什么有些东西没有被加入 Skill。
