# Brand Visual Director 示例说明

这个教学案例展示怎样把“我想做一个品牌设计 Skill”缩小成第一版可测试能力：

> 当品牌或设计团队需要建立早期视觉方向时，这个 Skill 会通过 Brief、受众、定位、行业套路与视觉机会分析，帮助用户得到三套差异明确、可继续执行的视觉方向。

## 从 Idea 到 Skill

### 原始想法

“做一个万能品牌设计师。”

这个范围包含策略、命名、Logo、视觉系统、包装和落地物，无法在 V0.1 中可靠验证。

### 缩小后的问题

只处理一件事：把品牌 Brief 转成三套早期视觉方向。最终 Logo 和完整品牌规范明确排除在外。

### 提取出的专业方法

- 先把通用定位词转成具体取舍；
- 检查行业同质化套路；
- 为每个方向选择不同的视觉机制；
- 不允许只换颜色；
- 输出后做差异检查并修复重复方向。

### 为什么只需要一个文件

这个示例的流程和规则还不长，一个 `SKILL.md` 已经足够。没有真实需求证明需要 Router、scripts、API 或独立知识库，所以 V0.1 不添加它们。

## 试用方式

可以提供一份品牌 Brief，并用以下请求开始：

> 请根据这份 Brief 生成三套视觉方向。品牌面向第一次购买精品咖啡器具的城市用户，希望专业但不让人紧张；避免传统黑金“高级感”。

观察它是否：

- 先提取 Brief 和假设；
- 只询问真正影响结果的缺口；
- 给出完整的 11 个方向字段；
- 让三个方向在至少三个核心视觉维度上不同；
- 发现重复时先修复再交付。

这个案例用于理解结构，不是所有品牌项目的通用答案。把自己的判断和案例提取出来，才会形成真正属于你的 Skill。
